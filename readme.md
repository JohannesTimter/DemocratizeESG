# About

DemocratizeESG is an open-source set of tools to evaluate the true environmental performance of corporations. 
[Climate Action 100+](https://www.climateaction100.org/about/) is an investor-led initiative to ensure the world’s largest corporate 
greenhouse gas emitters take necessary action on climate change in order to mitigate financial 
risk and to maximize the long-term value of assets.
We have collected 1350 Annual Reports from 170 CA100+ across the years 2020-2024 and have 
released the report collection on 
our [drive](https://drive.google.com/drive/folders/1ysF7PHBu29_0LGV-c22iwBoPx8X_NS9N?usp=sharing).
